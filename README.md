Produto Educacional - PROFMAT UFAL (Maceió) 2026

Esse site é uma plataforma online para coloração de mapas, problema de otimização combinatória estudado na pesquisa de dissertação para trabalhar o pensamento heurístico.
Na plataforma há diferentes mapas: reais, criados como desafio e mapas em superfícies 3D representadas no plano. 
As fontes dos mapas estão citadas logo abaixo de cada um deles, bem como algumas curiosidades e resultados de coloração de mapas.
